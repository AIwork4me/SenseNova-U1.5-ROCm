## Attempt 2 addendum — runtime dependency completion (2026-08-26T11:02:31Z)

After installing the two nightly wheels, 'import torch' failed:
  ImportError: libhipfile.so.0: cannot open shared object file
Root cause (packaging model, NOT a bug in this validation):
  - torch/lib contains ONLY libc10_hip.so + libtorch_hip.so (+libtorch_rocshmem.so,
    libaotriton_v2.so): the upstream nightly ROCm wheel does NOT bundle the ROCm
    userspace; it links the system/venv ROCm.
  - readelf -d torch/lib/libtorch_hip.so shows RPATH:
      $ORIGIN/../../_rocm_sdk_core/lib:$ORIGIN/../../_rocm_sdk_core/lib/rocm_sysdeps/lib:$ORIGIN/../../_rocm_sdk_libraries/lib:$ORIGIN
    i.e. the wheel's supported model is the AMD pip ROCm distribution installed in
    the SAME venv (repo.amd.com/rocm/whl-multi-arch) — without it, libs resolve from
    system /opt/rocm-7.2.1 (soname-compatible except libhipfile.so.0, ROCm>=7.14-only).

Resolution (official runtime, installed into the venv):
  .venv-pytorch-nightly-rocm714/bin/python -m pip install \
      'rocm-sdk-core==7.14.*' 'rocm-sdk-libraries==7.14.*' 'rocm-sdk-device-gfx1100==7.14.*' \
      --extra-index-url https://repo.amd.com/rocm/whl-multi-arch/
